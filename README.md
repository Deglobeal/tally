# Tally

> A modern personal finance and daily task management app for tracking todos, expenses, balances, and financial activity in one place.

## Overview

Tally is a modern productivity and personal finance application designed to help users manage everyday tasks while keeping track of expenses, balances, and financial activity in one place.

The application combines task management with simple financial tracking, providing a practical foundation for users who want to organize their daily activities and monitor their money.

## Features

* Daily task management
* Expense tracking
* Balance tracking
* Financial activity management
* Responsive user interface
* Mobile-friendly design
* Persistent data storage
* Modern dashboard experience
* Customizable application structure

## Technology

* React
* Vite
* Tailwind CSS
* Node.js
* PostgreSQL
